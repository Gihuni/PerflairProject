# 🏷️ Perflair: Fragrance E-Commerce Platform

> **Spring MVC 기반의 회원 관리 및 커뮤니티 중심 향수 쇼핑몰 서비스**
>
> **Perflair**는 사용자가 편리하게 향수를 탐색하고, 관리자는 쇼핑몰 데이터를 효율적으로 제어할 수 있는 이커머스 웹 애플리케이션이다. Spring Framework 5 환경에서 구조적인 데이터 처리를 위한 MVC 패턴을 구현하고, 회원 정보 관리 및 권한별 CRUD 비즈니스 로직을 전담한다.

---

## 🛠️ 내가 담당한 기능 및 구현 내용 (My Roles)

### 🔐 1. 회원 정보 관리 시스템
* **전화번호 기반 아이디 찾기 구현**
  * 사용자가 입력한 전화번호를 Oracle DB와 대조하여 일치하는 아이디 조회.
  * 개인정보 보호를 위해 Java 문자열 제어로 아이디 뒷자리 마스킹(예: `gih***`) 처리.
  * JavaScript를 활용해 화면 내 팝업창(Modal)으로 안전하게 안내.
* **랜덤 임시 비밀번호 발급**
  * 비밀번호 분실 시 전화번호/이메일 정보 검증 후, Java 코드로 임의의 랜덤 비밀번호 생성 및 팝업 제공.
  * 로그인 후 마이페이지에서 즉시 비밀번호를 변경하도록 유도하는 방어 코드 작성.

### 👥 2. 개인화 서비스 (마이페이지 제어)
* **비밀번호 재인증 기반 정보 수정**
  * 마이페이지 보안 강화를 위해 사용자가 비밀번호를 다시 입력했을 때만 수정 폼 활성화.
  * 아이디를 제외한 항목(비밀번호, 전화번호, 이메일, 주소 등)의 백엔드 업데이트(`UPDATE`) 로직 구현.
* **통합 마이페이지 동선 연결**
  * 마이페이지 내에서 `주문내역(확인/취소)`, `장바구니(결제/취소)`, `공지사항 및 질의응답` 내역으로 화면 새로고침 없이 매끄럽게 이동하도록 라우팅 동선 설계.

### 🛡️ 3. 관리자(Admin) 커뮤니티 및 피드백 관리
* **공지사항(Notice) 권한별 CRUD 제어**
  * 비회원/일반 회원은 읽기만 가능하도록 제한하고, 관리자 권한일 때만 추가/수정/삭제가 가능하도록 분기 처리.
  * 공지사항 추가 시 작성 날짜 자동 등록, 수정 시 수정한 날짜로 갱신되는 MyBatis 쿼리 전담.
* **고객센터 질의응답(Q&A) 피드백 시스템**
  * 소비자가 작성한 질문을 관리자 페이지에서 모니터링하고, 해당 문의에 대한 답변을 추가 및 수정할 수 있는 양방향 소통 인프라 처리.

## 💻 Environment & Tech Stack (개발 환경)

* **OS:** Windows 11 Home
* **IDE / Tool:** Eclipse (4.30.0.RELEASE), VS Code, Oracle SQL Developer
* **Backend:** Java 17 (jdk-17.0.15), Spring Framework 5.0.7.RELEASE
* **Data Access / DBMS:** MyBatis, Oracle 21c
* **Frontend:** HTML5, CSS3, JavaScript, JSP, Bootstrap 3.3.2
* **Third-Party API:** KakaoLogin

---

## ✨ 성장 및 느낀 점

* **Spring MVC 패턴 확립:** Controller ➡️ Service ➡️ DAO(MyBatis) ➡️ DB(Oracle)로 이어지는 정형화된 데이터 흐름을 바닥부터 구현하며 백엔드 아키텍처의 기초를 다짐.
* **권한별 분기 로직 이해:** 접근 권한(비회원, 회원, 관리자)에 따라 JSP 화면 UI 노출과 Controller 요청 처리 권한을 다르게 제어하는 비즈니스 로직 설계 능력 향상.
* **예외 처리 경험:** 아이디/비밀번호 찾기 시 입력값 검증, 마이페이지 정보 수정 전 2차 비밀번호 확인 등 실무 중심의 데이터 검증 흐름을 깊이 있게 고민함.
